# Notebooks

This directory contains Jupyter notebooks for interactive development, analysis, and visualization.

## Suggested Notebooks

1. **01_dynamics_exploration.ipynb** - Explore spacecraft dynamics and quaternion kinematics
2. **02_controller_design.ipynb** - Design and tune LQR and MPC controllers
3. **03_learning_residuals.ipynb** - Train and evaluate residual dynamics models
4. **04_performance_comparison.ipynb** - Compare controller performance
5. **05_visualization_demo.ipynb** - Demonstrate real-time visualization with Meshcat

## Usage

Install Jupyter:
```bash
pip install jupyter notebook
```

Launch notebook server:
```bash
jupyter notebook
