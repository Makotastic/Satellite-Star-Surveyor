# Reports

This directory contains final reports, figures, and documentation.

## Contents

- **figures/** - Generated plots and visualizations
- **final_report.pdf** - Final project report
- **presentation.pdf** - Project presentation slides

## Report Structure

The final report should include:

1. **Introduction**
   - Problem statement
   - Objectives
   - Approach overview

2. **Background**
   - Spacecraft dynamics
   - Quaternion representation
   - MPC formulation
   - Learning-augmented control

3. **Methodology**
   - System modeling
   - Controller design (LQR, MPC, Learning-MPC)
   - Residual learning approach
   - Implementation details

4. **Experiments**
   - Test scenarios
   - Performance metrics
   - Comparison results

5. **Results and Analysis**
   - Tracking performance
   - Control effort
   - Stability analysis
   - Learning effectiveness

6. **Conclusion**
   - Summary of findings
   - Future work
