# Satellite Star Surveyor
This project implements high-level planning, state estimation, and control for a space telescope in orbit.

## Notable Components
- Model Predictive Control (MPC) for nonlinear control and path planning
- Multiplictive Extended Kalman Filter (MEKF) for nonlinear state estimation
- High Level Star Planner which intelligently selects next viewing targets for optimal observation time
